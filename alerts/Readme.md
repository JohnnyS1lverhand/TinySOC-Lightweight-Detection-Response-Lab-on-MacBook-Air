# Alerts

This directory contains definitions, templates, and logic for security alerts in your monitoring and incident response system.

## Purpose

Alerts are used to notify administrators or security teams about important events, anomalies, or threats detected in the infrastructure.  
This folder organizes alert configurations and integrations with various notification channels.

## Structure

- **Webhook/** - Integrations for sending alerts to external systems via webhooks.
- **Telegram/** - Scripts and instructions for sending alerts to Telegram (see [Telegram/README.md](/alerts/Webhook/Telegram/Readme.md)).

## How to Use

- Add or modify alert definitions according to your monitoring and detection requirements.
- Configure integrations in the relevant subfolders to deliver alerts to your preferred channels (e.g., Webhook, Telegram).
